# Cold

Python Discord user-account automation project.

## Setup

1. Use Python 3.10+.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Put your account token in `config.json` under `tokens`.
4. Run: `python main.py`

Developer: @cries

Automating user accounts is against Discord's Terms of Service; use this only if you understand the account-risk implications.
